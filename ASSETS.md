# Asset provenance

All art and audio were generated for this project; none come from an existing game.

| Asset                                          | Source                                                          |
| ---------------------------------------------- | --------------------------------------------------------------- |
| Card scenes (`cards/t{tier}-{spice}.webp`, 15) | Higgsfield, GPT Image 2.6, engraving style, one anchor as reference |
| Guild vignettes (`guilds/*.webp`, 10)          | Higgsfield, GPT Image 2.6, same engraving style                 |
| Home hero (`misc/hero.webp`)                   | Higgsfield, GPT Image 2.6, same engraving style                 |
| Spice tokens, icons, favicon                   | Hand-written SVG (`apps/web/src/art/`)                          |
| Sound effects (`audio/*`)                      | Higgsfield, Mirelo text-to-audio                                |
| Card slide sound                               | Synthesised with ffmpeg (filtered pink noise)                   |
| Background music (`audio/music`)               | Higgsfield, ElevenLabs Music v2.5, instrumental                 |

Fonts: Fraunces and Figtree via Google Fonts (SIL Open Font License).
