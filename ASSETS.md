# Asset provenance

All art and audio were generated for this project; none come from an existing game.

| Asset                                          | Source                                                          |
| ---------------------------------------------- | --------------------------------------------------------------- |
| Card scenes (`cards/t{tier}-{spice}.webp`, 15) | Higgsfield, GPT Image 2.6, one style anchor reused as reference |
| Guild banners (`guilds/*.webp`, 10)            | Higgsfield, GPT Image 2.6                                       |
| Table rug, home hero (`misc/`)                 | Higgsfield, GPT Image 2.6                                       |
| Spice token medallions, favicon                | Hand-written SVG (`apps/web/src/art/SpiceIcon.tsx`)             |
| Sound effects (`audio/*`)                      | Higgsfield, Mirelo text-to-audio                                |
| Card slide sound                               | Synthesised with ffmpeg (filtered pink noise)                   |
| Background music (`audio/music`)               | Higgsfield, ElevenLabs Music v2.5, instrumental                 |

Fonts: Fraunces and Figtree via Google Fonts (SIL Open Font License).
